# 文献综述与方法创新路线图

> 基于 17 篇 C 题相关文献的系统梳理，按问题分组

---

## Q1 — 销售分布规律与相互关系

### 主流方法矩阵

| 方法 | 使用频次 | 代表文献 | 评价 |
|---|---|---|---|
| **Spearman 相关系数** | 4/5 篇 | 陈妙霞、高佳楠、Liao(英)、杨若涵 | 数据非正态 → 必选 Spearman（Pearson 失效） |
| **K-means++ 聚类** | 3/5 篇 | Liao(英)、高佳楠、苏茜 | 按销量量级+波动性聚类品类/单品 |
| **系统聚类** | 1/5 篇 | 杨若涵 | 层次聚类辅助，非主流 |
| **SARIMA 预测** | 2/5 篇 | 陈妙霞 | 连带做预测，非纯分析 |
| **Prophet 分解** | 1/5 篇 | 吴萌 | 剥离趋势-季节-节假日后分析残差相关性 |

### 文献局限

1. **所有文献只做了一阶相关**——Spearman/Pearson 只能捕捉线性单调关系，无法识别非线性、尾部依赖或条件独立结构
2. **聚类仅用销量量级+波动两个维度**——没有考虑时间序列形状相似性
3. **缺乏因果方向**——相关性不区分"谁驱动谁"
4. **单品层面分析薄弱**——5 篇中仅苏茜和聂宇旋做了单品层面，但只跑相关系数矩阵（251×251），无结构化降维

### 创新方向

| 编号 | 创新点 | 具体做法 | 差异化价值 |
|---|---|---|---|
| **I1** | **品类关联网络 + 去时间趋势** | 用 Prophet 剥离各品类日销量的 trend + seasonality，对**残差**计算 Spearman + 尾部相关系数，构建品类关联网络图 | 去除伪相关（共同时间趋势造成的虚假关联），文献中无人做 |
| **I2** | **DTW 时间序列形状聚类** | 对 251 个单品归一化后计算 DTW 距离矩阵，用层次聚类按**销售形状**聚类（而非仅量级），与 K-means 结果交叉验证 | 所有文献只用 K-means 在静态统计量上聚类，DTW 捕捉销售形态相似性 |
| **I3** | **格兰杰因果检验 + 互信息网络** | 在品类层面做 Granger causality test + 互信息，区分"谁影响谁"和"非线性关联强度" | 文献全停留在相关，未涉及因果方向 |

## Q2 — 品类级补货与定价

### 主流方法矩阵

| 模块 | 方法选择 | 代表文献 | 评价 |
|---|---|---|---|
| **需求预测** | SARIMA | 陈妙霞、聂宇旋 | 经典但需平稳性 |
| | ARIMA | 杨若涵、赵雪专(英) | 同上 |
| | LSTM | 聂森 | 非时序专用，需大数据 |
| | **Prophet** | **曹宇轩、吴萌** | 可解释性强，自动处理节假日+趋势断点 |
| **价格-销量关系** | 双对数需求模型 | 聂森 | 直接估计价格弹性，经济学理论支撑 |
| | 线性回归 | 高佳楠、赵雪专(英) | 太粗糙 |
| | 对数/幂函数拟合 | 聂宇旋 | 按品类分别选最优函数形式 |
| **优化求解** | 非线性规划 + 贪心 | 聂宇旋 | 简单但可能非全局最优 |
| | 模拟退火 (SA) | 高佳楠、曹宇轩 | 全局搜索，但参数敏感 |
| | **遗传算法 (GA)** | 苏茜、曹宇轩 | 鲁棒，适合非线性 |
| | GBest-PSO | 聂森 | 收敛快 |
| | **报童模型 (Newsvendor)** | **吴萌** | 唯一一篇引入随机优化的，理论最优 |

### 文献局限

1. **预测和优化分离**——几乎所有文献先用时间序列预测销量，再把预测值输入优化模型，**忽略预测不确定性**
2. **价格弹性几乎无人真正使用**——聂森的双对数模型是唯一例外，但估计出的弹性没有植入优化目标函数
3. **成本加成率被当作固定外生变量**——文献一致设固定加成率（如 20%），没有把加成率本身作为决策变量
4. **损耗率被当作确定性**——所有文献直接把附件 4 的固定损耗率代入成本，不做随机化

### 创新方向

| 编号 | 创新点 | 具体做法 | 差异化价值 |
|---|---|---|---|
| **I4** | **报童模型 + 价格弹性内生化** | 品类日需求 = Prophet 趋势预测 × 价格弹性修正项（lnQ = α + βlnP + ...），加成率 r 作为决策变量进入 Newsvendor 利润函数，对每个品类每一天求解 (r*, Q*) | 唯一将价格弹性估计和报童随机优化融为一体的方案，文献中没有 |
| **I5** | **品类需求协方差矩阵约束** | 利用 Q1 的品类关联（Spearman 矩阵）作为优化模型的约束——补货量之间的比例关系应尊重品类协同/替代结构 | 所有文献独立优化各品类，忽略品类间联动 |
| **I6** | **批发价预测 + 鲁棒优化** | 对附件 3 批发价用 Prophet/SARIMA 做区间预测，在优化中设置批发价不确定性集（box/ellipsoid），求解鲁棒对等模型 | 文献只做点预测，不处理批发价不确定性 |

## Q3 — 单品选择与补货定价

### 主流方法矩阵

| 模块 | 方法选择 | 代表文献 | 评价 |
|---|---|---|---|
| **单品评价** | VIKOR 多属性决策 | 聂森 | 量化单品"需求度"，主观权重依赖 |
| | 贪心算法 | 苏茜、聂宇旋 | 按利润/销量排序选品 |
| **单品预测** | Prophet + SARIMA | 复用 Q2 框架 | — |
| **组合优化** | NSGA-II 多目标 | 聂森 | 唯一考虑"需求+收益"双目标的文献 |
| | 贪心 + 求解器 | 苏茜 | 实用但非全局 |
| | SA/GA 离散化 | 高佳楠、曹宇轩 | 处理离散 SKU 选择 |

### 文献局限

1. **选品和定价分开做**——先选品，再对选中单品做定价优化，缺乏联合优化
2. **品类需求满足的量化粗糙**——几乎无人真正定义"尽量满足各品类需求"的数学约束
3. **单品间的替代/互补关系未利用**——Q1 得出的单品关联信息在 Q3 中消失了
4. **最小陈列量 2.5kg 被当作固定下界**——没有考虑空间与销量的权衡

### 创新方向

| 编号 | 创新点 | 具体做法 | 差异化价值 |
|---|---|---|---|
| **I7** | **双层规划：品类总量控制 + 单品联合优化** | 上层 = Q2 的品类最优补货量（报童解）作为 Q3 品类需求目标；下层 = 单品选择+补货量+定价的联合优化，品类需求偏差作为惩罚项进入目标函数 | 补货量+定价+选品同时求解，而非分步 |
| **I8** | **单品网络中心度选品** | 用 Q1 构建的单品关联网络（DTW 聚类 + Spearman），选品时优先选择网络中心度高的"枢纽单品"作为锚点，保证品类内部多样性 | 首次将网络分析引入单品选择，文献中无前例 |

## Q4 — 数据采集建议

### 文献方法
- 灰色关联分析（高佳楠）——判断外部因素影响
- 定性论证（曹宇轩、吴萌）

### 创新方向

| 编号 | 创新点 | 具体做法 |
|---|---|---|
| **I9** | **基于前三问建模缺陷的证据驱动建议** | 而非泛泛列举"天气、节假日"，每一建议附带：我们在 Qx 中遇到了什么问题，采集 Y 数据如何解决 |

## 推荐技术路线总图

```
数据层 (data-auditor-cleaner)
  │
  ├── Q1: Prophet 去趋势 → Spearman + DTW + Granger → 品类-单品双层次网络
  │       I1 · I2 · I3
  │
  ├── Q2: 双对数需求弹性 + Prophet 区间预测 → 报童模型(加成率内生)
  │       + 品类协方差约束 + 鲁棒优化(批发价不确定性)
  │       I4 · I5 · I6
  │
  ├── Q3: 双层规划(上层品类目标, 下层单品联合优化)
  │       + 单品网络中心度选品
  │       I7 · I8
  │
  └── Q4: 证据驱动数据建议
          I9
```
